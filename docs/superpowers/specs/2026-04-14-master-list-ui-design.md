# 職員マスタ・利用者マスタ UIブラッシュアップ 設計書

**日付:** 2026-04-14
**対象ファイル:** `public/index.html` — `renderStaffMaster()` / `renderPatientMaster()`
**ステータス:** 承認済み

---

## 背景と目的

職員マスタ・利用者マスタの一覧画面は現状「名前のみ」の表示で、以下の課題がある。

- 部屋番号・週パターン設定状況・担当コースが一覧から見えない
- 検索機能がなく、大人数のとき目的の人を探しにくい
- 職員マスタは「ロール別カード」だが、ロール未設定の「未分類」が多いと見づらい

対象ユーザーは **管理者・現場スタッフ両方**。主な用途は「特定の人をすぐ見つけること」と「週パターン設定漏れの確認」。

---

## 設計方針（3ペルソナ合意）

| ペルソナ | 要件 |
|---|---|
| UX専門家 | 名前左固定・バッジ右寄せで視線の流れを統一。未設定は警告色で注意を促す |
| 介護現場スタッフ | 部屋番号でも検索できる。未設定フィルターで設定漏れを素早くチェックできる |
| アクセシビリティ専門家 | 行高44px以上。色+テキスト両方で状態を表現（色覚多様性への配慮） |

## 利用者マスタ — 詳細設計

### レイアウト変更

**現状:** 2〜4列グリッド（名前ボタンのみ）
**改善後:** 単一列ハイブリッドリスト（列ヘッダー + 1行ごとにバッジ表示）

### 列構成

| 列 | 幅 | 内容 |
|---|---|---|
| 名前 | flex-1 | 利用者名（font-black italic uppercase、13px） |
| 部屋 | 52px | 部屋番号（DM Mono、11px） |
| 週パターン | 90px | `✓ 設定済`（緑バッジ）/ `⚠ 未設定`（黄バッジ） |
| コース | 70px | その利用者が当日スケジュールに登録されているコース名（10px、opacity-55）。スケジュールがない日は空欄 |

### コース列のデータソース

`state.scheduleRows` を参照し、`patient === patientName && office === state.activeOffice` に一致する最初のエントリの `course` を表示する。複数コースある場合は最初の1件のみ表示。スケジュールが存在しない場合はセルを空欄にする（エラー表示なし）。

### 検索・フィルター

- **検索バー:** 名前・部屋番号のインクリメンタル検索（`input` イベントでリアルタイムフィルター）
- **フィルタードロップダウン:** 全員 / ⚠ 未設定のみ / ✓ 設定済のみ（`<select>` 要素）

### 未設定行のハイライト

週パターン未設定の行は背景を `#fffbeb`（黄みがかった白）にして視覚的に区別する。
バッジテキストは `⚠ 未設定`（色+記号+テキスト）とし、色覚への依存を避ける。

### 週パターン設定済み判定ロジック

`state.courseAssignees` に `{office}|{day}|{tab}|{course}` 形式でデータが入っている。
利用者が **いずれかの曜日・コースに1件以上アサインされている** 場合を「設定済み」とする。

```js
function hasWeeklyPattern(patientName, office) {
  return Object.keys(state.courseAssignees).some(key => {
    const assignees = state.courseAssignees[key];
    return key.startsWith(office + '|') &&
      Array.isArray(assignees) &&
      assignees.includes(patientName);
  });
}
```

### ソート

デフォルトは部屋番号の数値昇順（`numeric: true`）。現状の五十音順は部屋番号ソートに変更する。
（理由: 現場スタッフは部屋番号で利用者を識別することが多いため）

## 職員マスタ — 詳細設計

### レイアウト変更

**現状:** ロール別3列カードグループ
**改善後:** 五十音行ラベル区切りの単一列フラットリスト

### 列構成

| 列 | 幅 | 内容 |
|---|---|---|
| 名前（五十音順） | flex-1 | 職員名（font-black italic uppercase、13px） |
| 職種 | 120px | ロール名バッジ（例: `PT`、`OT`）。未登録は `—` |

### 五十音行ラベル

名前の読みの先頭文字をあ行〜わ行でグループ化し、区切りラベル（黒背景・白文字・9px）を挿入する。
日本語ソートは `localeCompare(b, 'ja')` を使用。

```js
const KanaGroups = [
  { label: 'あ行', chars: ['あ','い','う','え','お'] },
  { label: 'か行', chars: ['か','き','く','け','こ','が','ぎ','ぐ','げ','ご'] },
  // … さ〜わ行
];
```

実装上は `name` フィールドの先頭文字を `localeCompare` で判定し、グループを動的に生成する。

### 検索

- 名前のインクリメンタル検索のみ（部屋番号は不要）
- 検索中はグループラベルを非表示にし、マッチした名前のみフラットに表示

## 共通仕様

### カラー定義

| 用途 | 値 |
|---|---|
| 設定済みバッジ背景 | `#dcfce7`（緑100） |
| 設定済みバッジ文字 | `#16a34a`（緑600） |
| 未設定バッジ背景 | `#fef9c3`（黄100） |

| 未設定行背景 | `#fffbeb`（黄50） |
| 列ヘッダー背景 | `#F8F8F8`（uber-secondary） |
| 行ホバー背景 | `#F8F8F8` |
| 五十音ラベル背景 | `#2C2C2C`（uber-accent） |

### 行の最小高さ

CSS: `min-height: 44px` を各行に適用（タップターゲット確保）。

### 件数表示

リスト下部に `{表示件数} / {総数}名 表示中` を追加（検索/フィルター中は絞り込み後の件数を反映）。

### 既存UIとの互換性

- 各行クリックで既存の編集モーダル（`openPatientModal()` / 職員詳細）を開く動作は変更しない
- 「週間パターンを予定へ展開」ボタンは利用者マスタのヘッダー右に残す
- 「戻る」ボタンの位置・動作は変更しない
